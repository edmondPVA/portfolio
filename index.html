Order logging, automated.

Overview

Every test account meant eight manual steps.

Testers needed fresh accounts for the fiber ordering flow. Each one meant clicking through eight steps by hand, then typing the details into a tracker. It was slow and easy to get wrong.

The goal: one run creates a realistic customer, completes the order, confirms the result, and saves the details automatically.

Then: one row added to Google Sheets

log_order_to_sheet()

The logging step

What gets saved

After the confirmation page passes every check, log_order_to_sheet() signs in with a service account and appends one row to a tracker worksheet.

EnvironmentAccount typeAddressNameEmailPhoneDOBPIN
••••••••••••••••••••••••

One new row per completed order. Values are hidden here.

Safe by design

Logging runs only after the assertions pass, so the sheet holds working accounts only. A failed write prints a message instead of crashing the run.

Precision first

Automated, never careless.

The data saved matches exactly what was entered in the order.
